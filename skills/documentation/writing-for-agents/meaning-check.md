# 含义核对（本项目补充）

改写后对照原文；新写时对照已确认材料。重点核对删句、拆句、补主语和调整步骤的位置：

| 核对项 | 判断 |
|---|---|
| 事实与状态 | 主体、动作、因果和完成状态有依据，计划仍是计划 |
| 条件与例外 | 前提、范围、否定、顺序和例外仍作用于原来的步骤 |
| 不确定性 | 推测、待确认和限制保留，缺少证据不变成肯定结论 |
| 技术内容 | 数值、单位、版本、术语、命令和链接目标保持原意 |
| 要求强度 | 建议、必须、允许和禁止的力度不变 |

例如：“建议上线前测试，纯文档变更除外”不能改成“上线前必须测试”。含义不明时保留原文并指出疑点；只读任务只给建议，实际修改遵循当前授权。
