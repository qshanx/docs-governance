# 人机协作观察提示

仅在人机协作复盘解释笼统、遇到盲点或需要补查证据时，按问题参考。无需遍历全部环节或逐项生成建议；环境方法、主流程与读写边界以 [project-retro](SKILL.md) 为准。[来源与适配](SOURCE.md)。

## 人机协作

| 协作环节 | 观察与建议 |
|---|---|
| 目标与理解 | 目标、范围和完成标准是否一致，AI 是否及时暴露关键假设？考虑在影响执行的分歧处复述或澄清，已有材料可查证的先查证。 |
| 分工与决策 | 人负责的取舍与 AI 自主推进的事项是否明确？是否越权、反复确认或不必要等待？考虑明确决策时点，复用仍有效的同范围授权。 |
| 沟通与反馈 | 进展、风险和阻塞是否及时传达，用户纠偏后是否真正调整或重复同类错误？考虑让反馈进入后续行动与验证。 |
| 验证与交付 | AI 是否把职责内的验证推给用户，完成声明是否有对应版本和实际用户路径的证据？考虑让交付说明与已验证范围一致，缺少条件时说明未验证部分。 |
| 有效协作 | 哪次澄清、示例、任务拆分或反馈减少返工？保留有证据的有效做法、适用条件与反例，不从一次顺利合作推定普遍收益。 |
