# PR 审核

先读[必要检查](verification.md)，然后：

1. 搞清楚这个 PR 解决什么问题，成功标准是什么。
2. 先不看实现，你会怎么解决？记下简短方案，再读代码。
3. 对照两种方案审代码，判断是否正确、有无遗漏或更好的解法，区分缺陷与方案偏好。
4. 按附件完成测试与验收，验证实际行为，列出结果及未运行项。
5. 对明确问题给出建议及 Markdown `diff`，说明怎样验证；信息不足时列缺口。
