| 场景 | 规范处理与证据 |
|---|---|
| 已有十阶段资料和 Issue 需求池 | Skill 六类位置映射与模板均复用现有记录；不重建看板或重编号 |
| 收到原始 PDF，之后导出 Word | 原始 PDF 登记来源并保留；Word 关联 Markdown 主记录及修订，不能覆盖原始证据 |

## r3 分类与按任务读取复核（2026-09-23）

依据 PDR-20260923，针对 PE-9、PE-10 核对共享 Skill、Agent 路由、CLAUDE、入口模板和本项目映射。以下为规范文本场景复核，不是独立 Agent 执行或 token 压力测试。

| 场景 | 规范处理与证据 |
|---|---|
| 四类与十阶段重叠，例如访谈支持 PRD | 四类材料索引与六类管理登记链接原主记录，本项目没有搬迁或复制正文 |
| 修改单个需求 | 从索引定位修订／条款，核对验收、未决项、公共规则、依赖和后续确认；不默认读整目录 |
| 跨模块或调整整体范围 | 沿影响补读模块及整体 PRD 对应章节；摘要和搜索命中不能代替适用正文 |
| 追溯旧规则或询问来源 | 沿确认引用读取上游证据或历史，历史不自动替代当前基线 |
| 只修链接或排版 | 读取目标及直接引用，无关产品材料不加载 |
| 基线缺失、过期、确认冲突或远端不可访问 | 定向查找并核对主记录；无法确认时报告缺口，暂停依赖结论的修改而非猜测 |
| 文档多、上下文不足或全产品审查 | 分模块保留修订、覆盖和待查记录，补查跨模块规则；必要内容分批读完，不截断后宣称全量通过 |

PE-9、PE-10 的规范场景复核通过；真实宿主是否稳定遵循读序及实际上下文节省仍待业务项目试点。确定性审计只能核对结构和引用，不能监控阅读行为或背书语义覆盖。
