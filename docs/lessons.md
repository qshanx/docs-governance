## LESSON-001：按工作流判断 Skill 是否需要独立入口

- 条件与做法：候选 Skill 的触发、步骤、产物和停止条件相近时，先核对现有职责；现行判断方法见[规则落点检查](../skills/documentation/agent-workflow-governance/supporting-files/rule-placement.md#3-核对散落资料能否沉淀)。
- 证据与边界：本会话先明确批准新增 test-retro，随后要求“你们要合在一块儿”；[PRD](product/06-prd.md#pr-20261013统一项目复盘与经验生命周期)保留决定演变。早期实现当时有授权，后续合并不能倒推为未经批准；有独立调用价值的工作流仍可拆分。
- 状态：候选。现有规则已覆盖，尚无新需求中采用该方法减少重复入口的效果回执。
- 复验记录：独立有效应用 0 次。下次相邻能力需求中，记录职责比较、最终入口及后续是否仍发生职责重复；本次迁移和旧入口移除不当作提前判断方法已有效。
- 优化清单：尚未触发三次门槛；2026-10-13 本会话已交付初次候选建议，未升级。
- 拟落点／正式目标：复用上述规则落点检查，暂不新增同义规则。
