# 项目文档

这里记录本插件自身的需求、决策和验证；提供给用户项目的空白文档在 [templates](../templates/)，执行方法在 [Skills 总路由](../skills/documentation/docs-governance/SKILL.md)。

| 要解决的问题 | 入口 |
|---|---|
| 当前产品目标、需求与验收依据是什么 | [产品文档](product/README.md) |
| 为什么作出某项长期设计决定 | [架构决策](adr/README.md) |
| 某次审计检查了什么、发现什么 | [审计记录](audits/)；结论仅适用于记录中的版本与范围 |
| 从项目工作中积累了什么经验、哪些仍待复验 | [项目经验](lessons.md)；现行规则从条目的正式目标读取 |
| 查找已被替代的方案和评审过程 | [历史方案](archive/)；当前测试协作方法见 [test-collaboration](../skills/engineering/test-collaboration/SKILL.md) |
| 查找外部文章、方法比较与借鉴依据 | [研究资料](../research/README.md) |

当前架构见 [ARCHITECTURE](../ARCHITECTURE.md)，当前健康与待办见 [PROJECT_STATUS](../PROJECT_STATUS.md)。历史方案和审计通过记录不替代当前规则或当前验证。
